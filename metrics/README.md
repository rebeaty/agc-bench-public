# `metrics/` - scoring implementations

This directory contains metric implementations used by the AGC-Bench run specs.
They include exact-match and classification metrics, embedding and similarity
metrics, structured-output checks, pairwise preference metrics, and wrappers for
benchmark-specific scoring rules.

Cross-benchmark scoring conventions are documented in
`release_data/SCORING_NOTES.md`; per-benchmark fidelity notes are in
`audit/fidelity/`.
