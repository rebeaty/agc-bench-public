# `curation/` - catalog and onboarding records

This directory records how source benchmark candidates were identified,
screened, deduplicated, and converted into AGC-Bench implementations.

| Path | Purpose |
|---|---|
| `catalog/` | Source files behind the 497-row benchmark catalog released in `release_data/benchmark_catalog_497.csv`. |
| `onboarder/` | Public onboarding workflow and intermediate records used to turn accepted catalog entries into HELM scenarios and run specs. |

These files document benchmark selection and implementation. The primary score
release is in `release_data/`.
